    Selected work.

    Three problems from production, what I did about them, and what changed.

    Case 01Senior DevOps & Cloud Architect · 2025 — Present

    A multi-region platform that stays up

    Context
    AWS spread across more than 20 accounts, and a production cluster that can't go down.
    What I did
    Defined the infrastructure in Terraform, and moved delivery to GitOps: GitHub Actions builds, ArgoCD deploys to EKS in more than one region.
    Result
    99.99% uptime on the production cluster.
    TerraformEKSArgoCDGitHub Actions

    Case 02Cloud Engineer · 2022 — 2024

    Moving to the cloud without going offline

    Context
    Workloads had to move from on-premises servers to AWS and GCP while they kept serving traffic.
    What I did
    Built the target networks, compute and databases (VPC, EC2, RDS) across availability zones with auto-scaling, then moved traffic over with Route 53.
    Result
    More than 20 migrations with zero downtime, and infrastructure costs down 40%.
    AWSGCPRoute 53Multi-AZ

    Case 03Linux Administrator · 2020 — 2022

    A hundred servers, built by script

    Context
    More than 100 bare-metal and virtual servers on RHEL, CentOS and Ubuntu, each set up and hardened by hand.
    What I did
    Scripted the builds in Bash and Ansible, with the same hardening on every machine: SELinux policies and iptables.
    Result
    Deployment time down 70%, and zero breaches.
    AnsibleBashSELinuxRHEL
